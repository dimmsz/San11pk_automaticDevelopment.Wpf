# San11pk Automatic Development (WPF)

Steam 日本語版『三國志11 with パワーアップキット』向けに、マウス操作による内政自動化を検証する **試作ツール** です。

## 方針
- ゲーム実行ファイル・セーブデータ・ゲームバランスは変更しません。
- Windows のマウス入力を送信して「都市を左クリック → 内政 → 募兵 → 実行」を試します。
- 初期状態は **ドライラン（クリックしない）**。ゲームを操作する際は明示的にチェックしてください。
- 画面認識・メモリ参照・武将の未行動判定・ターン終了検知は **未実装** です。ゲームを見ながら手動テストしてください。

## 動作環境
- Windows 10/11 / .NET 9 Desktop Runtime または .NET 9 SDK
- Visual Studio 2022（.NET 9 / WPF ワークロード）
- 三國志11PK はテストしやすいウィンドウモードを推奨します。

## 使用方法
1. `San11pk_automaticDevelopment.Wpf.sln` を Visual Studio で開き、ビルド・実行します。
2. ゲームを起動し、アプリの「プロセス名」が実際の EXE 名（拡張子なし）と合っているか確認します。初期値は `San11WPK` です。
3. ゲームのマップ上で対象の都市にカーソルを合わせ、**Ctrl+Shift+1** で記録します（都市を左クリックするための位置です）。
4. ゲームの都市を自分で左クリックしてメニューを表示し、「内政」にカーソルを合わせ、**Ctrl+Shift+2** で記録します。続けて「募兵」に合わせ **Ctrl+Shift+3**、最後に実行ボタンに合わせ **Ctrl+Shift+4** で記録します。記録時、アプリはクリックしません。
5. アプリに戻り、最初は「ドライラン」で座標を確認します。動作確認後、チェックをオンにし、**都市を左クリックのみ → メニューまで → 実行まで** の順に試してください。最後の段階には確認ダイアログが出ます。
6. 緊急停止は **Ctrl+Shift+0** です。ゲームが最前面でなくなった場合も実行を中止します。

## 注意事項
- 右クリック操作を前提とした旧版の座標は、本更新で自動的に初期化されます。都市の位置から4項目を再登録してください。
- 表示解像度・ゲームの描画領域サイズを変えた場合は再記録が必要です。記録した座標はゲームウィンドウのクライアント領域相対です。
- 「内政」「募兵」がマウスオーバーで開くUIの場合、クリック方式の調整が必要です。
- 武将・資源の状態は確認しません。実行する前に募兵できる状態であることをゲーム内で確かめてください。
- ゲームの動作を実機で検証できていないため、ゲーム側のメニュー遷移や動作の保証はありません。
- 座標設定は `%LOCALAPPDATA%\San11pk_automaticDevelopment.Wpf\calibration.json` に保存されます。
